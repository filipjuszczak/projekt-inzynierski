# Projekt inżynierski WAB 2025

## Temat pracy: Aplikacja internetowa dla lokalnego kina

Aplikacja umożliwia użytkownikom przeglądanie repertuaru kina z uwzględnieniem m.in. terminu, gatunku filmu i ograniczenia wiekowego. Użytkownik może m.in. utworzyć konto, kupić bilet(y) na wybrany seans i wybrać miejsca na sali.

Zastosowane technologie:

- Next.js
- Postgres
- Prisma
- TanStack Query
- Tailwind CSS
- shadcn/ui
- Lucia Auth
- React Hook Form
- ky
- Lucide React
- Zod
- TypeScript
