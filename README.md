# Projekt inżynierski

## Temat pracy: Aplikacja internetowa dla lokalnego kina

Aplikacja umożliwia użytkownikom przeglądanie repertuaru kina z uwzględnieniem m.in. terminu, gatunku filmu i ograniczenia wiekowego. Użytkownik może m.in. utworzyć konto, kupić / zarezerwować bilet(y) na wybrany seans i wybrać miejsca na sali.

Zastosowane technologie:

- Next.js
- Postgres
- Prisma
- TanStack Query
- TanStack Table
- Tailwind CSS
- shadcn/ui
- Lucia Auth
- Zustand
- React Hook Form
- ky
- Lucide React
- Zod
- TypeScript
- UploadThing (platforma umożliwiająca przechowywanie plików)
- resend (platforma umożliwiająca wysyłanie wiadomości e-mail)
- Stripe (platforma odpowiedzialna za bezpieczne płatności)
